# Email Validator

## Problem Statement

Many users enter email addresses with incorrect formats, such as missing the `@` symbol, an invalid domain, or misplaced characters. Manually checking whether an email address follows the correct format can be inconvenient and error-prone.

The Email Validator project provides a simple Python-based solution to check whether an email address follows a valid email format using Regular Expressions (Regex).

## Scope of the Project

The project focuses on validating the basic structure and format of email addresses. It can identify whether an entered email address follows the defined validation pattern.

The project is intended for basic email format validation and does not verify whether the email account actually exists or whether the domain can receive emails.

## Target Users

- Students learning Python programming and Regular Expressions.
- Beginners who want to understand input validation.
- Developers who need a simple example of email format validation.
- Users who want to quickly check the format of an email address.

## High-Level Features

- Accepts an email address as input.
- Validates the email format using Regular Expressions (Regex).
- Checks for common email formatting requirements.
- Displays whether the entered email address is valid or invalid.
- Simple and beginner-friendly Python implementation.
