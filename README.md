# Email Validator

A simple Python project that validates email addresses using Regular Expressions.

## Features

- Checks whether an email address is valid
- Uses Regex to check email format
- Simple and beginner-friendly
- gives valid or invalud output 

## Technologies Used

- Python
- Regular Expressions(REGEX)

 ## How to Run

### 1. Install Python
Make sure Python is installed on your system.

### 2. Clone the repository
git clone https://github.com/mishraAnanya210906-creator/Email-Validator.git

### 3. Open the project folder
cd Email-Validator

### 4. Run the program
python email_validator.py

### 5. Enter an email address
Enter an email address when prompted to check whether it is valid.

## Dependencies

This project uses Python's built-in re module, so no external packages are required.
